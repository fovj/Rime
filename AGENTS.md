# Rime Wubi86 JiDian IME Config

## Description

Rime 输入法 86 版极点五笔配置方案。这不是输入法本身，而是配置方案，跨平台共享（macOS 鼠须管、Windows 小狼毫、Linux 中州韵、iOS 仓、Android 同文）。

## Repo structure

- `*.schema.yaml` — input method scheme definitions (6 schemes: wubi86, numbers, pinyin, trad variants, mixed)
- `*.dict.yaml` — dictionary/词库 files, tab-separated `text\tcode\tweight`
- `*.custom.yaml` — user customizations patched on top of defaults
- `lua/*.lua` — Lua plugins for date/time output and single-char filtering
- `仓键盘布局/` — iOS Hamster keyboard layout
- `build/` — **generated by Rime**, never edit directly

## Key files

- `default.custom.yaml` — main user config: schema list, key bindings, punctuation
- `squirrel.custom.yaml` — macOS appearance (colors, font)
- `weasel.custom.yaml` — Windows appearance
- `wubi86_jidian.schema.yaml` — main Wubi86 scheme definition
- `wubi86_jidian.dict.yaml` — main dictionary with `import_tables` referencing sub-dicts

## Dictionary hierarchy

`wubi86_jidian.dict.yaml` imports:
- `wubi86_jidian_user` — personal words
- `wubi86_jidian_user_hamster` — iOS Hamster added words
- `wubi86_jidian_extra` — extended online word list
- `wubi86_jidian_extra_district` — region names (commented out by default)

## Editing workflow

1. Edit `.dict.yaml` or `.custom.yaml` files (tab-separated: `word\tcode\tweight`)
2. Trigger Rime **Deploy** (部署) to recompile
3. `build/` directory, `installation.yaml`, `user.yaml`, `*.userdb/**` are auto-generated and gitignored

## Conventions

- Dictionary columns: `text`, `code`, `weight`, `stem` (tab-separated)
- Weight impacts candidate ordering; main dict uses multiples of 10
- Sub-dicts are merged via `import_tables` in `wubi86_jidian.dict.yaml`
- `z` key: reverse lookup (pinyin) and repeat last input
- `；` and `'` for 2nd/3rd candidate selection by default
- Single-char mode: uncomment the `lua_filter` lines in schema's `filters` section
- After editing, always **Deploy** — there is no separate build/test step
